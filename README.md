# Langtiamo — итальянский с нуля

Приложение для изучения итальянского с нуля.

- **Курс A1 + A2 (21 модуль).** Порядок тем и грамматики — по учебникам Nuovo Espresso 1 (A1, 10 уроков + итоговый модуль) и Nuovo Espresso 2 (A2, 10 уроков); тексты, диалоги и упражнения свои. В каждом модуле: слова, грамматика по шагам, чтение (перевод любого слова по нажатию), аудирование, письмо с автопроверкой, говорение и тест (выбор ответа + ответы с вводом). Следующий модуль открывается после теста (от 70%), уровень A2 можно открыть сразу.
- **Проверка письма.** Свои правила для типичных ошибок A1–A2 (артикли и род, lo/gli/l', согласование глагола с подлежащим, essere/avere в passato prossimo, согласование причастия, piace/piacciono, ударения) + орфография через LanguageTool (маршрут `?a=check` функции). Доступна в заданиях «Письмо» и в окне «Проверка» рядом с переводчиком.
- 445 слов с интервальным повторением, 17 уроков грамматики по шагам, фразы и диалоги для жизни в Италии, тренировки на слух.
- Переводчик IT⇄RU (свой словарь + MyMemory через сервер, с кэшем).
- Уровни, награды, задания дня, напоминания в Telegram.

Работает как Telegram Mini App в боте **@langtiamo_bot** и как обычная страница: https://yerassyl-alimkul.github.io/langtiamo/

## Как устроено

| Часть | Где | Что делает |
| --- | --- | --- |
| `index.html` | GitHub Pages | Всё приложение в одном файле: и Mini App в боте, и сайт |
| Общий аккаунт | Supabase, таблица `pp_progress` | Один прогресс на бота и сайт. В боте вход автоматический (`initData`), на сайте — «Войти через Telegram»: одноразовый код, подтверждение кнопкой в боте, токен сессии на 180 дней |
| `supabase/functions/pianopiano-bot` | Supabase Edge Functions | Вебхук бота (`/start`, `/time`, `/remind`), приём статистики из Mini App (с проверкой подписи `initData`), рассылка напоминаний |
| Таблица `pp_users` | Supabase | Настройки напоминаний и краткая статистика (сколько карточек на повтор, серия) |
| Задача `pianopiano-remind` | pg_cron | Каждый час вызывает рассылку; напоминание приходит в выбранный час, если сегодня ещё не занимался |

## Настройка (уже сделано)

1. Секрет `PP_BOT_TOKEN` в Supabase → Edge Functions → Secrets.
2. Регистрация вебхука, команд и кнопки меню: открыть `https://sffknvpnbrgwmtlcouge.supabase.co/functions/v1/pianopiano-bot?a=setup`.
3. GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

Если адрес страницы поменяется, задай секрет `PP_APP_URL` и снова открой ссылку `?a=setup`.

## Команды бота

- `/start` — приветствие и кнопка приложения
- `/time 9` — час напоминания (0–23, по твоему часовому поясу)
- `/remind` — включить или выключить напоминания
